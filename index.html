FAQ

Questions, answered.

Does NexusAI send my source code to a third party?

No. NexusAI runs on isolated, single-tenant inference clusters and retains zero prompt or completion data by default. Enterprise customers can deploy the entire agent runtime inside their own VPC, so code never leaves your network perimeter.

How large a repository can it index?

The Pro plan comfortably indexes monorepos up to 5 million lines of code with incremental rebuilds on every commit. Beyond that, Enterprise clusters shard the semantic graph across nodes with no practical upper bound.

Can I review changes before they're merged?

Always. NexusAI's default mode opens a pull request with a full rationale, a diff summary and the test results attached. Auto-merge is opt-in and can be scoped to specific paths, labels or authors.

Which languages and frameworks are supported?

First-class support for TypeScript, JavaScript, Python, Go, Rust, Java, Kotlin, Swift, Ruby, PHP, C# and SQL — plus 100+ additional languages through tree-sitter grammars. Framework awareness covers Next.js, React, Vue, Svelte, Django, Rails, Spring and Laravel.
